# Confirmation delay and volume in the short-model comparison

These aggregates cover 32 matched synthetic worlds of 120 members each, with daily DAMS updates for 60 days under the central, witnessed and consensus record-process settings. Each row in `world-delay-counts.csv` reports a single world and process. The bins are the counts of records confirmed by the end of the run with creation-to-confirmation delays of exactly 0 through 60 days. The two other counts are the final confirmed and unfinished totals. The histograms were extracted from the 96 retained end states and checked against their manifests and summaries. All 183 recalculated conditional means match the thesis's frozen CDF input.

Run `python3 -I -S -B verify.py` in this directory with Python 3.10 or later. For each cutoff, the verifier sums bins through that cutoff, divides by the number of confirmed records in that world for the conditional curve, and averages across worlds. It divides those same counts by 120 for the second curve, then averages across worlds. `confirmation_counts.csv` supplies the latter to the figure. Neither curve follows incomplete records past day 60. The plots summarize the modeled review and settlement settings.
