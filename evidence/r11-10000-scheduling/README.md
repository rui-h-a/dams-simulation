# Scheduling the 10,000-member enterprise study

This reanalysis uses the recorded simulation and validation times of the 40 completed study arms. The documented layout puts the four arms of a world on the same host with four concurrent slots. It assigns each world the longest of its four arm durations and allows the next world to start after all four finish. The whole-world schedule also adds the matching prehistory phase from the ten retained prehistory receipts. The alternative assigns arms individually across hosts and assumes each slot can access the correct restored prehistory.

Run `python3 verify.py` with standard Python 3.9 or newer. It downloads the fixed input CSV from the public resource evidence and checks its SHA-256. To run offline, supply a local copy of that CSV as the only argument. The prehistory CSV exports 731-day counts, wall seconds and peak resident memory for each recorded world. The full-precision output is in `results.json`.

For either layout, the computed schedule finishes faster than the sum of the three shortest jobs. A better schedule therefore cannot put three jobs on one slot. If there are more jobs than slots, some jobs must be paired. The largest jobs can be assigned to single slots: if a singleton is shorter than a paired job, exchanging them cannot increase the longest slot time. For the paired jobs, matching shortest with longest minimizes the maximum pair sum by the same exchange argument. The verifier checks this two-job condition rather than applying the rule to arbitrary schedules.

These are ideal schedules, not end-to-end wall times. The analysis holds measured phase times constant. Only the explicitly labeled whole-world schedule includes prehistory. All schedules omit final output writing, journal hashing, transfer, queueing, retries and throughput changes with contention. Journal bytes describe the original final journals, and the reported RSS measures worker processes. Neither gives peak occupancy of a host filesystem or peak memory of an entire machine. The alternatives were not run.
