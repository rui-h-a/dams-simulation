# Voluntary exits and the BLS workplace benchmark

Run `python3 -I -S -B verify.py` in this directory. The standard-library verifier reproduces `results.json` from the frozen aggregate inputs without a network, simulation or original event journals.

The BLS input contains 180 seasonally adjusted monthly rates retrieved from the [public API](https://www.bls.gov/developers/) on 9 November 2026. It covers all private employment, establishments with 250–999 employees and establishments with at least 5,000 employees. The official [size-class method](https://www.bls.gov/jlt/sizeclassmethodology.htm) uses an establishment's peak employment during the twelve months before sample selection and assigns size until reselection. The [definitions](https://www.bls.gov/jlt/jltdef.htm) count quits through a reference month, excluding retirement and transfers, and measure employment for the payroll period including the 12th.

The model inputs contain only aggregated synthetic counts. The source readers use retained arm receipts, final-state rosters, daily trajectories and summaries. They reconcile exposure against entry/exit dates and daily rosters. They count records with the cause `voluntary_exit`, leaving retirements and other exits separate. The displayed model denominator is active headcount on the 12th, a proxy for BLS payroll employment. The rate multiplies the equally weighted mean of monthly rates by 12, so it is a flow per 100 roster or employment positions, not the annual probability that one worker leaves. The simulation rates are unadjusted.

The one-location 300-member founding scenarios use 57 worlds and cover 2020–2024. The 10,000-member multinational scenarios use ten worlds and branch on 1 January 2022. Model and BLS periods are matched within each comparison. The all-private series is a broad contextual reference for the multinational scenarios because organization-wide headcount does not determine each work site's size. The published numerical check estimates neither governance effects from BLS data nor a forecast for a particular organization.

For readers who already hold the matching source archives, the two extractors verify the source bindings and reconstruct the model inputs. `extract-founding-quits.py STUDY_DIRECTORY` writes CSV to stdout and provenance to stderr. `extract-main-quits.py --help` lists the archive and previous payback-provenance arguments. Original journals are outside this check.
