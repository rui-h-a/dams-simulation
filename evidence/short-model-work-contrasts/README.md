# Short-model work contrasts

The 60-day experiment uses 120 members in four guilds, daily authority updates and a central record. The table retains total synthetic work for five policies in each of 32 matched worlds. The extraction validates 160 retained summaries against their manifests and 9,600 daily output records.

Run python3 -I -S -B verify.py to divide each arm's work by its 7,200 member-days and calculate paired policy differences from linear credit. The output multiplies by 1,000 for the units used in the figure. Intervals use the 97.5th normal percentile and the standard error of the 32 world differences. Linear is zero by construction. The prespecified substantive criterion of 0.02 work units per member-day applies to the DAMS minus linear primary contrast.
