# Disposition of the formal 50,000-member comparison

[Amendment 12](https://github.com/rui-h-a/dams-simulation/blob/956725516ddac7f7c2336b0ccc23a69c5d7a27c5/docs/r11-formal-protocol.md) assigned ten worlds, three policies per world, two shared pre-adoption years and five post-adoption years. This packet reports that October comparison. The subsequent two-world and two-arm rerun follows the pilot roster and is outside this packet.

The retained inventory contains 4,653 progress objects. For each assigned world, the fixed plan and latest event were read by object generation and checked against their transport digest. Each latest event stream contains one successful prehistory record. The provider audit records removal of all ten instances. The observed prefixes contain no completed arm receipts or outcome files. These records establish prehistory resource measurements and an incomplete policy comparison. They do not establish recovery of the prehistory files or the results of any policy arm.

Run `python3 -I -S -B verify.py` in this directory. The program checks the extracted roster and recomputes the counts and ranges from the pinned evidence. It creates no simulation.
