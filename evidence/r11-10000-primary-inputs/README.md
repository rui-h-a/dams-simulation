# Four prespecified outcomes for the 10,000-member study

Run `python3 -I -S -B verify.py` in this directory. Python 3.11 or newer is sufficient. The verifier reads the 40 arm totals in `arm-inputs.csv` and emits 12 paired means, the underlying paired values, marginal 95% Student-t intervals, within-arm 95% Bonferroni intervals and Holm-adjusted p-values for both testing families. The reference is the retained performance-tier hierarchy. Each simulation covers 2,557 calendar days: two shared pre-adoption years and five after adoption. Worlds 1000–1009 are the independent observations. The verification-processing comparison between the process-change and retained hierarchy arms has zero paired variation. The report keeps that row in both family sizes and emits null intervals and p-values for it. Bonferroni intervals use four outcomes within each arm. The Holm adjustment is reported for four outcomes within each arm and 12 across the study.

Member-years equal active member-calendar-days divided by 365.25. Net operating result is revenue minus operating expense per member-year. Decision regret is regret units per available member-work-hour. Governance time sums review, appeal, governance and organizational verification hours per member-year. Verification processing is reported separately, per member-year. The thesis displays regret per million available member-work-hours.

The inputs are aggregate values extracted from the retained daily series and arm summaries. The archive member hashes were matched to the arm receipts before extraction. The verifier checks arithmetic on those aggregates. Independent event-level replay requires the original journals.
