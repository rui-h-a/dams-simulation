# Five years after adoption in the 10,000-member main study

Run `python3 -I -S -B verify.py` with Python 3.11 or later. The verifier runs offline using the standard library. Its 40 rows cover the same four arms in each of ten paired worlds. The post-adoption calendar runs from 1 January 2022 through 31 December 2026, inclusive, following the common history in 2020 and 2021. There are 1,826 post-adoption days per arm.

`arm-totals.csv` contains eight sums from the daily series and the count of completed first reviews. Each row carries the retained series, summary and arm-receipt SHA-256, plus a digest of the common prehistory for the eight daily accounting fields. `manifest.json` identifies the fixed execution sources and binds the exported table. These are arm-level synthetic totals for arithmetic reproduction. The original event journals and complete daily trajectories are outside this package.

Member-years are active member-calendar-days divided by 365.25. Net operating result is revenue less operating expense per member-year. Decision regret is reported per million available member-hours. Governance time adds review, appeal and governance hours to 0.025 organizational verification hour per completed first review, then divides by member-years. Each witnessed first review adds 0.2 verification-processing unit; the two central arms incur zero under this counter. The first-review count is reconstructed from the source model's 0.1 review hour per completed first review.

The verifier subtracts the hierarchy rate within each world, then reports the paired mean and a Student-t interval with nine degrees of freedom and Bonferroni adjustment across the 12 contrasts. An invariant contrast has a null interval. These post-adoption comparisons are exploratory. The registered seven-year endpoints and their inference are in the [main-study evidence](https://github.com/rui-h-a/dams-simulation/tree/2c921307a0aad405b515426c43c8ab156762fcd0/evidence/r11-10000-paired-results).
