# Founding-model closure and Dutch employer survival

The [Statistics Netherlands StatLine table 85204ENG](https://www.cbs.nl/en-gb/figures/detail/85204ENG) provides the underlying employer-demography cells. Reused under [CC BY 4.0](https://www.cbs.nl/en-gb/about-us/website/copyright). The JSON snapshots contain selected employer birth and five-year survival cells and metadata. The sector and size class refer to the employer-entry cohort. The 2023 survival counts are final and the 2024 counts provisional. Employer-entry status and continued employer status are distinct from legal founding, bankruptcy and the simulation's underfunding-triggered closure.

Run `python3 -I -S -B verify.py` for the public cohort arithmetic. The native section of `results.json` records 264 five-year simulation trajectories in 66 paired worlds at each of two founding sizes, with no closure or unfunded operating units. Native run evidence is checked against saved paired receipts and the common-end observations. Readers holding the corresponding verified archive and source-receipt manifest can repeat that check by supplying them as positional arguments, native root first. Neither command executes a simulation or infers a policy effect from the external cohort.
